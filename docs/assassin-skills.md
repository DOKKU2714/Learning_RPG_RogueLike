# 암살 스킬 공통 엔진

2026-10-19: `Skills!A20:Y37`의 18종을 시트 기반 공통 엔진으로 연결했다.
`Effects!A63:W78` 중 실제 상태 효과 9개, `EffectRules!A42:I101` 중 규칙 43개를 유지한다.
2026-10-19 점검 후 불필요한 효과 7개와 매개변수 행 17개는 값을 비웠다. 다른 행의 위치는 유지했다.
18종 모두 보상 활성화. 재빠른 행동은 기존 행동력 규칙, 초크는 기존 기절 효과를 사용한다.
정의 원본은 `scripts/build-assassin-pack.cjs`, 생성본은
`docs/skill-packs/assassin-skills-2026-10-19.json`이다.

`Skills.effectJson.combat.effectRuleIds`가 Effects의 ID를 참조한다.
`combatParameter` 규칙의 `statKey`는 재사용 가능한 동작의 설정 경로이며,
`valueFormula`에 실제 수식이나 설정값을 작성한다. 수식·문자열은 `valueMode=text`,
숫자·참/거짓은 `valueMode=json`이다. 예: `evasion.valueFormula` → `35+5*level`,
`evasion.durationTurns` → `2`. 서버와 브라우저 모두 동일한 EffectRules를 해석한다.
시트 규칙 누락은 오류로 처리하며 코드에 복제한 계수로 대체하지 않는다.
일회성 설정은 `Skills.effectJson.combat.effectRules`에 직접 작성한다.
여기의 `effectRules`는 기존 엔진의 실행 설정 객체 이름으로, `EffectRules` 시트를 참조한다는 뜻이 아니다.
별도 효과 참조는 `effectRuleIds`가 있을 때만 발생한다. 기존 배포 엔진에서도 이 경로를 지원한다.
조건부 추가 피해, 처치 시 쿨타임 초기화, 고정 피해, 피해 비례 방어막, 저체력 추가 타격,
처치 실패 반동은 지속 상태를 만들지 않으므로 별도 Effects 행을 만들지 않는다.
눈 찌르기는 `combat.onEachHit`에서 기존 `effect_v2_accuracy_down`을 재사용한다.
민첩한 움직임·반격·반사·맞다이·은신·유리대포·무지개 반사·여유로운 발걸음·처형자의 보상은
턴/스테이지 동안 유지하거나 후속 사건에 반응하는 실제 상태여서 Effects/EffectRules 정의를 유지한다.
기존 전투 저장 호환성을 위해 `assassinState` 등 저장 필드 이름은 유지했다.
기존 코드에서 직접 만들던 효과 정의는 제거하고 Effects의 이름·설명·중첩 정책을 사용한다.

- 기획의 n은 1부터 시작하는 스킬 레벨이며 실행 수식에서는 `level`을 사용한다.
- 눈 찌르기의 미지정 명중률 감소 지속시간은 2턴으로 정했다. 재적중은 갱신한다.
- 무지개 반사는 사용 다음 턴에만 활성화한다. 회피된 공격의 기본 피해에
  대상 표식과 받는 피해 보정을 적용해 반사하며, 발생하지 않은 치명타는 추첨하지 않는다.
- 민첩한 움직임은 방어막 유무를 갱신해 추가 회피율을 적용한다.
- 고정 피해는 방어막을 우회하고 직접 치명타·몬스터 방어 특성의 감산을 적용하지 않는다.
- 반사/반격은 독립 피해 종류로 실행해 직접 타격 트리거의 재귀 발동을 방지한다.
- 유리대포의 최대 체력은 만료 시 복원하되 현재 체력을 추가 회복하지 않는다.
- 여유로운 발걸음은 턴 종료로 행동력을 초기화하기 전에 남은 행동력을 보존한다.
- 처형자의 보상은 몬스터별 1회 기록을 남긴다. 스탯 저장 검증은 실제 처치 대상과
  보유 스킬을 확인하고 추가 포인트의 투자까지 검증한다.
- 새 런은 시트의 최신 정의를 읽으며, 기존 런은 시작 당시의 정의를 유지한다.
