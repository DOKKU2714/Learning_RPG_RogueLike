# 감전 스킬

2026-10-19 기획의 12종을 `Skills!A38:Y49`에 추가했다.
수식의 `level`은 1부터 시작하는 스킬 레벨(n)이다.

- `Effects!A21:W21`: 기존 감전 정의를 교체했다. 중첩당 명중률 감소를 제거했다.
- `Effects!A79:W83`: 감전 수용 증가, 비전도체, 피뢰침, 마찰 전하, 전기외투.
- `EffectRules!A38:I38`, `A102:I108`: 감전 추가 피해·소모 및 새 효과의 실행 규칙.
- 정의 원본: `scripts/build-shock-pack.cjs`; 생성 데이터: `docs/skill-packs/shock-skills-2026-10-19.json`.

감전은 실제 직접 피해가 발생하고 대상이 생존한 경우, 공격자의 현재 공격력을 기준으로
`2+0.1*attack` 추가 피해를 준다. 추가 피해마다 1중첩을 소모한다. 지속·추가·반사·반격 피해는
감전을 재발동시키지 않는다. 추가 피해는 원래 공격의 방어막 우회 여부를 물려받지 않는다.
해당 수식, 소모량, 방어막 정책은 EffectRules에서 관리한다.

별도로 명시되지 않은 사항은 다음과 같이 구현했다.

- 비전도체의 피해 감소는 다음 턴 종료까지 유지한다. 사용 턴에는 지속시간을 차감하지 않는다. 방어막 소진과 무관하며 감소율은 최대 100%다.
- 피뢰침은 다음 내 턴 시작에 기존 감전 중첩을 기준으로 피해를 준 뒤 새 중첩을 부여한다. 1회 발동한다.
- 비비기는 다음 감전 부여 동작 전체에 적용한다. 광역 부여 시 모든 대상에 적용하고 소모한다.
  감전 중첩을 받는 증가율과 부여하는 증가율은 곱해서 적용하며 최종 중첩은 반올림한다.
- 합선은 직접 피해와 그로 인한 감전 피해 후 잃은 체력을 기준으로 계산하고, 3 미만 잔여분은 버린다.
- 전기충격의 기절 조건은 새 감전 2중첩을 부여한 뒤 판정한다.
- 누전은 직접 피해의 감전 반응 후 남은 중첩을 소모해 다른 생존 적 모두에게 같은 수를 부여한다.
- 전도체 투척은 각 적의 감전을 소모한 뒤 각 적에게 자신의 소모 중첩 수만큼 감전 추가 피해를 준다.
  이 피해 자체는 감전을 재발동시키지 않으며, 전투당 1회 사용할 수 있다.

공통 연산은 `directHitDamage`, `consumeStacks`, `modifyReceivedStacks`, `modifyAppliedStacks`,
`consumeOnApply`, `incomingReductionIfEffect`, `triggerActions`이다. 스킬 ID별 분기는 없다.
`triggerActions`는 JSON 설정의 `actions`, `minTurnOffset`, `maxActivations`를 읽으며,
`stacksRounding=floor`는 스킬의 감전 부여 중첩 계산에서 사용할 수 있다.

실제 시트 저장값 510개를 읽어 확인했다. 검증은 감전 개별 동작·서버/브라우저 일치와
암살·발화·쿨타임·즉시 반응 회귀 검사를 포함한다. 인증된 실게임 플레이 검증은 하지 않았다.
