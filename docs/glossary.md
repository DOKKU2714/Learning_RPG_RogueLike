# 카드 옆 용어 설명

연결된 스프레드시트의 `Glossary` 탭에서 관리한다.

| 열 | 내용 |
| --- | --- |
| `keyword` | 카드에서 찾을 단어이자 설명 패널의 제목 |
| `description` | 해당 단어의 설명. 일반 텍스트이며 줄바꿈 가능 |

헤더 아래에 한 행씩 추가한다. 단어나 설명이 빈 행은 표시하지 않는다. 같은 단어가 여러 행이면 첫 번째 행을 사용한다. 단어는 카드의 제목과 설명에 포함되어 있는지 검사하며, 같은 카드에서 여러 번 나와도 설명은 한 번 표시한다.

스킬·기본 행동·스킬 및 스탯 보상·강화 전후 비교·스탯 목록·아이템 카드에 적용한다. 마우스를 올리거나 키보드로 포커스하면 카드 또는 스킬 상세창 오른쪽에 표시한다. 오른쪽이 좁으면 왼쪽, 양쪽이 좁으면 아래쪽을 사용하며 화면 안에 배치한다. 긴 패널은 스크롤 가능하다. Escape 또는 카드 선택 시 닫힌다.

기본 용어 22개를 실제 시트에 입력했다. 효과 동작을 바꾸는 표가 아니므로, 효과 수식과 조건을 수정했다면 이 설명도 맞춰 수정한다.

설명은 기존 게임 데이터와 함께 런 시작 시 고정된다. 시트 읽기 캐시는 10분이며, 수정 후 캐시가 갱신된 새 런에서 반영된다. 코드의 운영 배포는 별도로 필요하다.
