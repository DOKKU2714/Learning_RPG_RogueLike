# 스킬 설명 서식

`Skills.description`에 다음 태그를 입력합니다. 카드, 스킬 상세, 강화 미리보기와 따옴표 안의 플레이버 설명에서 사용합니다.

| 입력 | 표시 |
| --- | --- |
| `[b]내용[/b]` | 굵게 |
| `[i]내용[/i]` | 기울임 |
| `[u]내용[/u]` | 밑줄 |
| `[s]내용[/s]` | 취소선 |
| `[color=#ffcc00]내용[/color]` | 지정 색상 |
| `[br]` 또는 셀 내부 줄바꿈 | 줄바꿈 |

예: `[b]강타[/b][br]적에게 [color=#ff6655]{damage} 피해[/color]를 입힙니다.`

태그를 중첩할 수 있고 연 순서의 반대로 닫습니다. 색상은 `#RGB`, `#RRGGBB`만 허용하며, 해당 영역의 숫자와 상태명 자동 색상보다 우선합니다. 기존 `{damage}`, `{calc:...}` 등 계산 토큰은 그대로 사용합니다. 따옴표로 감싼 문장은 기존대로 플레이버 설명으로 분리됩니다.

HTML과 임의 CSS는 실행하지 않습니다. 지원하지 않는 태그와 잘못된 색상은 문자로 표시됩니다. 닫히지 않은 태그는 설명 끝에서 자동으로 닫습니다. 서버 전투 계산이나 시트 구조를 바꾸지 않는 표시 기능입니다.
