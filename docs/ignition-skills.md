# 발화 스킬 교체 (2026-10-19)

## 2026-10-19 실행 경로 점검

실제 런타임은 `Skills.effectJson`, `Effects`, `EffectRules`의 현재 정의를 읽는다.
코드의 스킬별 ID 분기나 수치표로 18종을 실행하지 않는다. 불씨 방패는 Skills의 `onBlock`,
태양인은 `onDamage`, 그 외 중첩·추가 피해는 공통 `combat.onEachHit`/`actions`를 사용한다.
엔진에는 `targetBurn` 등 발화 중첩 변수를 계산하는 ID 참조와 구형 `debuff_burn` 호환 경로가 남아 있다.

실제 시트 읽기에서 `Effects!A2:W2` / `EffectRules!A2:I2`는 중첩당 최대 체력의 **3%**,
피해 후 **1중첩 소모**로 확인했다. 아래의 초기 작성용 pack/내보내기 스크립트는 이전 기획인
1.5%·자동 감소 없음이므로 현재 시트에 그대로 다시 덮어쓰면 안 된다.
이번 점검에서는 발화 시트의 밸런스 값을 수정하지 않았다.

`outputs/ignition-skills-2026-10-19/발화_스킬_18종_burn통일.xlsx`에 플레이어 스킬 18개, 효과 4개, 효과 규칙 4개와 수치 계산·적용 안내가 들어 있습니다.

## 적용

1. 변경한 `SkillService.gs`, `SharedRuleEngine.gs`, `BattleService.gs`, `RewardService.gs`, `Battle.html`, `UiStyles.html`을 업로드하고 웹앱을 새 버전으로 배포합니다.
2. 기존 Skills에서 플레이어 스킬을 교체합니다. 몬스터 전용 `ms_` 및 `effectJson.monsterSkill` 행은 유지합니다. 열 순서가 다르면 영문 헤더에 맞춰 복사합니다.
3. 기존 `effect_v2_burn` 효과 행과 해당 EffectRules 전체를 이 파일의 효과 및 턴 종료 규칙 1개로 교체합니다. 부가 효과 3종은 추가하거나 같은 ID 행을 교체합니다. 이전 `skill_ignition_*` 스킬, `effect_ignition*` 효과와 규칙은 삭제합니다. 다른 효과·아이템·몬스터 데이터는 유지합니다.
4. `clearRuntimeCaches()`를 실행하고 새 게임을 시작합니다. 기존 진행 스냅샷과 영구 보유 스킬 ID는 자동 변환하지 않습니다.

Skills는 사용자가 전달한 25개 컬럼 순서로 내보냅니다. `actionPointCost`, `rarity`는 E·F열이며, `concept`부터 `rewardPlanned`까지 기획 정보는 R:Y열입니다. 복사 범위는 A1:Y19이고 끝의 빈 두 컬럼은 제외합니다. 게임은 헤더 이름으로 데이터를 읽으므로 열 순서 변경을 위한 런타임 코드 수정은 필요하지 않습니다.

## 수식과 동작

- 기획의 n은 1부터 시작합니다. 새 JSON은 `level` 변수를 사용하여 기존 n=level−1 스킬과 호환됩니다.
- 쿨타임은 사용한 턴을 기준으로 셉니다. 1턴에 사용한 쿨타임 1·2·3 스킬은 각각 2·3·4턴에 다시 사용할 수 있습니다. 쿨타임 0은 같은 턴에도 재사용할 수 있으며, 행동력과 최대 사용 횟수 제한은 적용됩니다. 시트의 쿨타임 숫자는 변경하지 않습니다.
- `description`의 `{calc:...}`는 기존 UI 계산 템플릿입니다. 숫자로 바꾸지 않아야 강화 및 능력치 변경 시 다시 계산됩니다.
- 스킬 ID는 `skill_v2_burn_01`~`18`, 발화 상태는 `effect_v2_burn`, 컨셉 태그는 `burn`입니다. 기존 v2 발화와 ID를 통일했습니다. 초기 버전의 `debuff_burn`은 예전 스냅샷·몬스터 호환을 위해 유지하며 새 스킬은 `effect_v2_burn`을 사용합니다.
- 발화는 턴 종료에 중첩×최대 체력×0.015 피해를 주고 방어막으로 흡수합니다. 중첩 자동 감소는 없습니다. 원소 피해 이벤트와 디버프 적용 순간의 스냅샷을 포함해 연출·아이콘을 갱신합니다.
- 플레이어 방어막 제거를 턴 종료 효과 뒤로 옮겨 잔여 방어막이 발화를 흡수하게 했습니다. 턴 종료에 생성되는 방어막도 다른 일반 방어막과 같이 해당 턴 종료에 제거됩니다.
- 사용자 확인: 횃불 피해 `(0.8+0.1n)×공격력+2+n`, 회피 감소 2턴간 `(5+5n)%p`, 자기 발화 확률 `30−5n%` 및 `20−5n%`, 폭발은 소모 중첩×`(선택한 적 최대 체력×0.02+5)`, 모든 대상은 적 전체이며 ‘자신 포함’만 예외입니다.
- 화염 스프레이와 라이터의 `+0.1n`은 원문대로 별도 고정 피해 항입니다. 가스누출의 스택 배율은 자기 피해에도 적용합니다. 확률은 0~100%, 음수 자기 피해는 0으로 제한합니다.
- 추가 이름: 불씨 방패, 화중 방어, 불씨 던지기, 열기 회수.
- 열기 회수는 원문대로 0중첩에서도 행동력 1을 회복하며 n≥6이면 2를 회복합니다. 부채질은 증가 후 선택 대상 중첩으로 광역 피해를 계산합니다.
- 태양인은 이번 턴 포함 3턴 동안 직접·추가·발화 피해 및 방어막 피해에도 반응합니다. 효과를 재사용할 때 같은 스킬의 트리거는 갱신됩니다.

## 재생성과 확인

번들 Node와 `.tmp_spreadsheet/node_modules`의 번들 의존성 경로를 사용합니다.

```powershell
node scripts/build-ignition-pack.cjs
node scripts/export-ignition-workbook.mjs
node --test --test-name-pattern '^ignition' tests/ignition-skills.test.cjs
```

기획 JSON은 `docs/skill-packs/ignition-skills-2026-10-19.json`입니다. 엑셀의 원본 셀 값 일치, 계산 재실행, 오류 셀 검사, 5개 탭 렌더링을 확인합니다. 발화 테스트는 서버·로컬 브라우저 경로를 함께 검증합니다.

기존 일반·복합 스킬 테스트는 58개 통과했습니다. 복합 스킬의 반환 객체 비교·기존 스킬 행 검증 2개와 업그레이드 미리보기 테스트의 누락된 테스트 보조 함수 오류 6개는 변경 전 HEAD에서도 동일하게 실패합니다.
