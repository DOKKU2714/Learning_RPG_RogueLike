# 런 레벨과 경험치

새 런은 레벨 1, 경험치 0으로 시작한다. 레벨과 투자한 능력치는 해당 런 안에서만 유지된다. 기존 진행 중인 런도 레벨 정보가 없으면 레벨 1로 처리한다. 레벨 정보는 Runs.statsJson의 levelProgress에 저장하므로 Runs에 열을 추가할 필요가 없다.

## 경험치 설정

Monsters의 선택 열 `experience`에 일반 몬스터별 기본 경험치를 설정한다. 열이나 값이 없으면 일반 30을 사용한다. 보스·최종 보스는 고정 100 EXP를 지급한다. 열은 관리자 함수 `migrateMonsterExperience()`로 추가할 수 있다.

- 층 배율: `1 + (층 - 1) × 0.2`
- 풀이 배율: `(0.5 + 평균 정답률 × 0.5) × 평균 문제 풀이 효율`, 최소 0.25, 최대 2
- 획득 경험치: 기본 경험치 × 층 배율 × 풀이 배율을 반올림, 최소 1
- 다음 레벨 필요 경험치: `100 + (현재 레벨 - 1) × 25`
- 보스·최종 보스: 층·풀이 배율과 experience 열에 관계없이 100 EXP. 레벨 상승은 필요 경험치를 충족할 때만 발생

정답률은 그 몬스터가 살아 있는 동안의 플레이어 정답 수 ÷ 전체 답변 시도 수이다. 오답 재시도도 시도 수에 포함한다. 기본 공격, 스킬, 수비에 사용한 문제와 포기도 포함하며, 포기한 문제의 풀이 효율은 0이다. 평균 풀이 효율은 해결한 문제별 최종 효율의 평균이다. 질문 없이 처치하면 정답률·효율 모두 100%를 적용한다. 지속 피해·반사·광역 처치도 몬스터 인스턴스별 한 번만 지급한다.

예: 1층 일반 몬스터의 정답률 100%, 평균 효율 100% → 30 EXP. 정답률 50%, 평균 효율 100% → 23 EXP. 정답률 100%, 평균 효율 150% → 45 EXP.

## 스탯 투자

레벨당 포인트 3개와 스킬 강화 1회를 받는다. 여러 레벨이 한 번에 오르면 합산한다. 경험치 5마다 볼 하나(나머지는 마지막 볼)가 사방으로 퍼진 뒤 게이지로 들어온다. 도착할 때마다 게이지와 +EXP를 갱신하고 Xp.mp3를 조금씩 다른 피치로 재생한다. 경험치가 레벨 경계를 넘으면 화면 전체가 번쩍이며 LevelUP과 LevelUp.mp3를 재생한다. 승리 시 경험치 흡수가 끝난 뒤 레벨업 선택을 처리하고 체력 재생과 보상을 표시한다. 스탯은 전부 배분하기 전에는 확정할 수 없고 확정 전에는 ±로 되돌릴 수 있다. 수치는 기본값만 표시하다가 투자하면 노란색 `101 (+1)` 형태로 표시한다.

강화 창은 보유한 강화 가능 스킬 중 하나의 레벨을 1 올린다. 강화 불가 스킬은 제외하며 후보가 없으면 창을 생략한다. 사용 내역은 levelProgress.skillUpgrades에 저장하고, 서버에서 레벨별 한도·보유 여부·강화 가능 여부를 검사한다. 6스테이지는 휴식과 보유 스킬 강화 중 하나를 선택한다.

| 능력치 | 포인트당 증가 |
| --- | --- |
| 공격력 | 1 |
| 방어력 | 1 |
| 최대 체력 | 1 |
| 체력 회복 | 1 |
| 명중률 | 3%p |
| 회피율 | 2%p |
| 치명타 확률 | 1.5%p |
| 치명타 피해 | 5%p |
| 문제 풀이 효율 | 최소·최대 각각 2%p |

최대 체력 투자 시 증가한 최대 체력만큼 현재 체력도 보충한다. 명중 수치는 100을 넘겨 상대 회피율을 상쇄할 수 있고, 회피율을 차감한 최종 적중 확률은 0~100%로 제한한다. 회피율·치명타 확률은 기존 100% 상한을 따른다. 스탯을 반영한 다음 보상 회복량을 갱신하며, 원래 승리 시각은 유지한다.
